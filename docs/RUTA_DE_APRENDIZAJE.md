# Ruta de aprendizaje (tutor Flutter)

Cada lección: teoría corta → tú escribes el código → revisamos juntos. Yo no escribo todo por ti.

1. **Entorno + primer arranque**: instalar Flutter, `flutter doctor`, correr en simulador iOS desde Xcode. Entender widgets, `build`, hot reload.
2. **Estructura y estado**: recorrer este código. Tarea: añadir modo "personalizado" (diálogo con duración).
3. **Persistencia**: Hive/Drift, Repository Pattern. Guardar sesiones completadas.
4. **Platform Channels iOS**: Swift + `FamilyControls`, targets y entitlements en Xcode.
5. **Platform Channels Android**: Kotlin + `UsageStatsManager` + AccessibilityService.
6. **Regla de desbloqueo**: cuenta regresiva, razón, tiempo concentrado.
7. **Dashboard y estadísticas**, luego **hábitos**.
8. **Contenido de aprendizaje**, notificaciones, onboarding y pulido de UI.
